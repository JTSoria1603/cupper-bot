# cupper_motor_controller

ESP-IDF firmware for controlling the **4 DC motors** of the Cupper robot. Implements speed and direction control via PWM (LEDC) and direction pins compatible with L298N-type drivers.

---

## Overview

The module manages four motors in a **holonomic** configuration (mecanum / omnidirectional wheels):

| ID | Motor |
|----|-------|
| `MOTOR_FRONT_LEFT` | Front left |
| `MOTOR_FRONT_RIGHT` | Front right |
| `MOTOR_REAR_LEFT` | Rear left |
| `MOTOR_REAR_RIGHT` | Rear right |

Each motor is controlled with **two direction pins** (IN1 / IN2) and **one PWM channel** generated by the ESP32 LEDC peripheral.

## PWM Configuration

| Parameter | Value |
|-----------|-------|
| Timer | `LEDC_TIMER_0` |
| Mode | `LEDC_LOW_SPEED_MODE` |
| Frequency | 1 000 Hz |
| Resolution | 10 bits (0 – 1023) |
| Channels used | 0, 1, 2, 3 |

Speed is specified as an integer percentage in the range **[-100, 100]**:
- Positive → forward (`IN1=1, IN2=0`)
- Negative → reverse (`IN1=0, IN2=1`)
- Zero → brake (`IN1=0, IN2=0`)

---

## Public API

```c
// Initializes GPIOs and PWM channels for all motors
void motor_controller_init(void);

// Sets the speed of a single motor (-100 to 100)
void motor_set_speed(motor_id_t motor_id, int speed);

// Sets the speed of all 4 motors simultaneously
void motor_set_all(int fl, int fr, int rl, int rr);

// Stops a single motor
void motor_stop(motor_id_t motor_id);

// Stops all motors
void motor_stop_all(void);
```

---

## Usage Example

```c
#include "cupper_motor_controller.h"

void app_main(void)
{
    motor_controller_init();

    // Move forward at 40% speed for 2 seconds
    motor_set_all(40, 40, 40, 40);
    vTaskDelay(pdMS_TO_TICKS(2000));

    motor_stop_all();
}
```

## Build & Flash

Requires **ESP-IDF v5.x** configured in your environment.

```bash
# From the project root
idf.py set-target esp32   # adjust for your chip
idf.py build
idf.py flash monitor
```

## Dependencies

- `driver/gpio.h` — direction pin configuration
- `driver/ledc.h` — PWM signal generation
- `esp_log.h` — serial console logging
- `FreeRTOS` — task management (`vTaskDelay`)
